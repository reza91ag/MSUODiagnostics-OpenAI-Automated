7.1 LICENSE USAGE TELEMETRY

The MSUO kernel uses an asynchronous, best-effort ("fire-and-forget")
notification mechanism to inform the Licensor's analytics backend of
license usage. Its purpose is to record the most recent known usage of
a license and support aggregate license-usage analytics.

The notification is designed to operate independently of the primary
application execution lifecycle. Failure to deliver an analytics
notification does not, by itself, prevent or interrupt application
execution or replace the kernel's license verification requirements.

Telemetry is intended to be limited to a pseudonymous license identifier
and a last-usage timestamp. The telemetry mechanism must not transmit
application payloads, business data, application source code, end-user
content, passwords or private signing keys. Analytics results may be
aggregated and anonymized. Where a license identifier or network metadata
can be linked to an identifiable person, such information is treated as
personal data rather than anonymous data.
